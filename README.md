## 本地预览
双击 `本地预览.command`，或命令行：
```
cd ~/wedding-invitation && python3 -m http.server 8899
```
然后打开 http://127.0.0.1:8899

> 注意：必须通过 http 服务打开，直接双击 index.html（file:// 协议）会因浏览器安全策略加载不了内容。

## 对原站做的改动
1. **URL 补丁**：原代码强制要求网址形如 `/board/v5/xxx/数字`，否则崩溃白屏。已改为匹配失败时回退默认值 —— 因此可部署在任意域名、任意子目录下。
2. 关闭了广告位、访问量统计打点、底部"投诉"链接；隐藏了平台标题栏与模板作者署名。
3. CSS 中的绝对路径改为相对路径，移除残留的微信外链图片。
4. 删除了宽屏模式下的侧边二维码面板、三处广告容器与秀米广告块的 DOM。
5. 背景音乐转码为 AAC 并默认自动播放。
3. 内容数据源指向本地 `data/show.json`。

## 关于音乐自动播放
已默认开启。但浏览器有硬性策略：无用户手势时禁止出声，这一点无法绕过。
因此 `index.html` 末尾的 `autoBgmBoot` 脚本做了接管——
- 微信内：监听 `WeixinJSBridgeReady`，真正做到打开即播；
- 普通浏览器：用户**手指一碰屏幕/鼠标一点**（哪怕只是开始滑动页面）音乐立刻响起，并同步点亮右上角按钮。

也就是说读者几乎察觉不到需要交互。

## 部署

注意：CSS 中若出现 `url(/xxx)` 形式的绝对路径，在子目录部署下会 404，必须写成 `url(../xxx)`。
